Toner flipper zero app reset for printer RICOH SP 112SU

In order to compile:
Install python

Install ufbt 
pip install ufbt

to build app run ufbt

Flipper Pin	GPIO PINS
PIN 9	- 3V3	VCC (Power)
PIN 8, 11, or 18	- GND
PIN 15	PC1 / SCL	SCL (Clock)
PIN 16	PC0 / SDA	SDA (Data)
